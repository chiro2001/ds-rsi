# 按位置读出的辅助课程

持续读取门控首批500微批后，48个自由查询的完整代码仍0%；首字母91.67%、单个数字100%，三位后缀分别25%、10.42%、16.67%。20个英语teacher-forced查询显示门控确实保持开启，但对应后缀的payload优势仍约0。因此保持gate不足以学会对后缀位置的语义读出。

`ab-v5-indexed-digits` 在不改动v1–v4文件、源事实、支撑ID、负例或CF改动位置的前提下，把部分完整代码问题改为“从左数第n位后缀数字，只输出一个数字”。目标来自已观察到的代码，问题只包含实体与位置；CF两种变体的问题完全相同，目标数字不同。

训练时，仅CF改动位于后三位且确定性hash抽样命中一半时使用辅助题，约占事实episode的30%；其他事实继续完整代码，保持任务不变。每个episode仍只有一个回答，避免新增多条probe稀释40%保持占比或改变原全局查询归一化。辅助目标为数字+EOS两个token，CF第一分歧位置为0，因此不依赖此前已经生成的代码前缀。

dev/test默认仍全部输出完整代码，原M5的完整EM、payload消融与语言保持门槛保留。`evaluate_m_only.py --probe-view indexed` 是显式辅助诊断，按回答字符位置分项，不能把字母/单数字的EM当作完整记忆验收。它需要v5数据版本；正式评测不加该开关。

实际Qwen tokenizer对960个配对样本审计通过：训练354条完整/126条辅助，开发480条全部完整；三个后缀位置均覆盖，最大源26token、回答输入82token。辅助监督恰为两个token、分歧在第一token、检索索引不见答案、答案不能写入M。见 [tokenizer审计](../reports/indexed-digits-real-tokenizer-audit.json)。

完整217项CPU测试通过。三rank完整NPU暂停/恢复对照延长到16微批，实际覆盖8个辅助episode，所有权重、优化器、RNG、游标、账本逐位一致。早先5微批证明没有覆盖到辅助样本，不能作为这项新增课程的恢复证据；正式证据为 [含覆盖的恢复](../reports/pretrained-npu-indexed-digits-recovery-covered.json)。

课程转换采用新run `ab-A-v5-indexed-01`，从 `ab-A-anchor1-lookup-01` 第500微批显式导入权重，保留位置池化和lookup门控。原完整状态保留，新run优化器/游标/RNG重启，来源链已用6,853,808学生token，剩余A预算23,146,192。首批上限1000微批，每100微批完整保存。继续该run只用 `--resume`，并显式指定v5数据身份。
