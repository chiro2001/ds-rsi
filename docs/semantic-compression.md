# 语义压缩与持续写入

当前已实现时间/来源条件化的压缩原语、紧预算持续写入，以及 D 内容的数据生成和独立目标函数。正式 D 训练器、完整恢复、摘要寻址与能力评测尚未接入，不能把未训练 Consolidator 的输出视为有意义的长期记忆。

`MemoryQwen.consolidate_records` 仅接收完成且同 stream/codec 的至少两条记录。压缩输入是子 slots 加上每个子 slot 的时间、角色、来源类型、层级及已知壁钟标志编码。逻辑锚点取子记录最大 source_end+1，壁钟特征锚点取已有子时间的最大值；提交可见性另以最大 visible_after 核验。当前或未来问题、答案、较晚提交时刻以及子摘要的推迟提交均不参与内容计算，递归压缩同样成立。

摘要的 source 范围覆盖子记录，level 增加，child_refs 保存直接来源。可见时间可以延后但不能早于任何子记录；同样的子记录在不同较晚提交时刻产生相同 slots/keys。只有全部子记录时间已知时，摘要才对外标记已知 wall_time，避免把部分未知时间升级成确定时间。

运行时优先压缩已存的最多四条记录。当剩余旧记录不足两条，或旧记录集合无法减小，已完成 incoming 与旧记录共同压缩，并以一次原子事务替换。无需先把 incoming 放入满预算存储。配置无法容纳任何摘要时明确报 BudgetExceeded；异常不部分删除子记录。正常预算下可反复摘要→摘要继续写入，测试已覆盖仅容纳一个摘要、连续25次写入和24层压缩。

冻结的已训练 LoRA 同样属于冻结增量，checkpoint 的 `frozen_auxiliary` 会保存它；它不在原始底座文件内，不能只依靠原始权重指纹恢复。

D 的内容训练约定：学生只见摘要与独立负例，清空 KV/GDN/conv，答案不能写入 M。支撑必须位于第一组四个叶中，随后使用“旧摘要+三条新叶”逐级压缩，在3d+1个叶规模下真实经历深度1/2/4/8。程序真值提供摘要后的回答 CE；叶教师只有在无答案输入的自由生成正确时，才启用 teacher→summary 的 top32+tail KL。教师 forcing loss 或低 CE 不能作为开启 KL 的依据。

`ab-d-compression-v1` 将支撑位置随机分布在第一组四叶，train/dev/test 实体命名独立，反事实只改变支撑值；开发与测试另提供最新叶和最早负例的细节保留探针。`CompressionObjective` 固定已有 Writer/Reader/地址/时间编码/主干与 LoRA，仅训练 Consolidator，学生回答仅使用最后一条摘要，叶教师使用第一组四叶。筛查使用与正式 M-only 相同的单 token 前缀和生成路径，拒绝用并行 BF16 GDN 前缀替代。教师分布停止梯度，学生输出头与 KL 保留梯度；源段、学生回答、教师筛查中的全部实际前向输入以及筛查通过后的分布前向分别计数，复用的源记录不重复记成教师编码。

CPU 专项验证覆盖真实四档递归链、独立 KL 梯度、冻结参数、筛查答案隔离及 EOS/预算两种计数路径。这些是实现证据；尚无 D 正式训练、独立压缩能力或 NPU 完整恢复证据。先通过 A/B 门槛，再启动正式 D 训练。

内容阶段仅训练 Consolidator，已有 Writer、Reader、地址、TimeSource、语言主干和 LoRA 冻结。后续单独用叶/摘要混合池适配摘要寻址，报告实际 top8 必要组 coverage、answer-free 自由回忆、递归深度分项和禁用/反事实 payload 消融。压缩训练不能替代此前 A/B 达标或语言保持验收。
