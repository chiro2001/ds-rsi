# 潜在记忆相关文献与后续方向

检索日期：2026-10-20。材料限原论文、会议论文与作者官方仓库；本文是文献分析和实验设计，不代表已完成复现或验证。以下优先级是针对本项目的判断，不是论文间的统一排行榜。

## 对本项目的主要判断

当前A阶段主要学习从记忆还原完整校验码或指定字符，粗粒度AddressEncoder仍冻结。最新RS1完整评测单候选68/96、双候选1/96，native保持通过。记忆内容对输出有作用，但按问题选择记录尚未建立。不能由此确定Writer信息不足、Reader竞争、寻址或底座能力中的某一个是唯一原因。

文献最值得迁移的三个方面是：以证据条件教师监督最终行为；同一记忆对应多种问题；把记录选择与内容解码分开诊断。近期先修正任务设计并建立教师上界，再比较训练目标。层次化经历记忆、在线快权重作为后续路线。

## 重点文献

### 1. TransMem：证据条件自蒸馏

**TransMem: Transforming Hidden States into Memory for Large Language Models**，arXiv:2607.29032，2026-07，已核对v1方法正文。

其教师与学生共享冻结底座。教师只看正确证据E和问题Q，学生看含干扰的完整长上下文C，并用稀疏历史hidden states生成有门控的残差修正；在答案轨迹上最小化教师到学生的输出分布KL。论文中主干不更新，梯度通过冻结上层传到新增模块。

**可借鉴**：让我们的M-only学生接近“看过正确证据的底座”，而不只依靠单一正确字符串CE或attention质量。训练时可对正确内容、无关内容、相同实体不同属性、跨记录问题使用统一行为监督。

**边界**：论文学生仍接触完整上下文，方法不是我们清空短期状态后的独立M-only复现。其训练骨干包括Qwen3-4B、Qwen2.5-14B、Llama3.1-8B，正文报告单A100训练；不能据此保证0.8B/5080上的能力与资源开销。我们应只迁移监督思想，学生不能重新拼接源原文。

### 2. Cartridges：同一记忆服务多种问题

**Cartridges: Lightweight and general-purpose long context representations via self-study**，arXiv:2506.06266，2025，已核对v1正文和消融。

冻结LLM，直接优化一小组虚拟KV；围绕同一语料生成多样对话，再用上下文蒸馏训练该KV。目标是让一个表示应对不同请求，且能够组合多个Cartridge。论文对比了问题生成方式和蒸馏/next-token目标，支持在其设置中增加问题多样性和使用分布蒸馏。

**可借鉴**：一次写入同一组事实，分别问不同实体、不同属性、当前/过去、比较/汇总、无证据问题。训练和评测都要求答案随问题变化，削弱固定区域抽取策略。

**边界**：每个语料的KV需要离线优化，区别于我们的通用Writer一次前向写入新经历。原文说明其Llama-8B高质量Cartridge构建约需8张H100节点30分钟；借鉴数据和目标，不照搬离线训练成本或宣称零成本写入。

### 3. M+：内容与可检索地址分开处理

**M+: Extending MemoryLLM with Scalable Long-Term Memory**，arXiv:2502.00592；ICML 2025版本亦已查到，方法核对v1正文。前身**MemoryLLM**为arXiv:2402.04624，ICML 2024。

M+增加长期latent memory和共同训练的检索器，使用query/key投影选择记忆；写入和生成分别使用LoRA。它提供了“内容如何存”和“当前问题取什么”的显式训练机制。

**可借鉴**：在固定Writer产生的内容上先审计/验证局部记录选择，再测试内容融合，避免所有责任都由slot attention同时承担。查询改变时，所选记录也应可检验地改变。

**边界**：这是本项目的工程提案，不是M+原文要求冻结Writer。原论文是Llama-3.1-8B、8张A100；我们的全局AddressEncoder仍属后续B阶段，不能把局部Reader实验默认为正式开启B或默改旧run。

### 4. ElasticMem：按问题分配记忆预算，允许抑制记录

**ElasticMem: Latent Memory as a Learnable Resource for LLM Agents**，arXiv:2605.30690，2026-05预印本，已核对v1方法。

离线构建冻结latent bank，每条记录含检索key和内容hidden-state cache。查询产生检索控制状态，预算策略为每条候选分配0到上限的latent tokens，经过投影后注入生成。通过GRPO共同优化使用过程。

**可借鉴**：双候选不必让两条记录同等进入读取。可以研究查询条件的record-level权重/抑制，测试选错或无关记录时能否不给内容通道施加干扰。此处不同于我们冻结的全局lookup gate。

**边界**：论文把LoCoMo和LongMemEval的QA转为多选题并输出选项编号，不能将其QA分数直接类比我们的完整码自由生成。论文包含LoRA reasoner、策略与RL，对0.8B未有直接证明。近期优先验证有标签的小型记录选择/门控对照，不先上GRPO；原文收益不可当作本项目收益预测。

### 5. ActiveMem：从独立事实到有依赖的经历

**ActiveMem: Dynamic Latent Memory Trees for Long-Horizon Agents**，arXiv:2609.33244，2026-09-27预印本，已核对v1正文。

将经历组织为有执行依赖的latent树，按当前执行状态取连贯路径，并学习扩展、检索和剪枝策略。其关注点是程序性任务依赖和跨任务干扰，不只是单条事实回忆。

**可借鉴**：后续C/D阶段将“做了什么、失败原因、当前进度、下一步”连成可更新结构，而不是把每条事件视为孤立、同等候选。为任务接续和压缩验收设计结构性指标。

**边界**：近期预印本结果仍需独立验证；层次结构和RL都增加变量。不能用层次记忆替代当前尚未通过的双记录读取验收。

### 6. Titans / FwPKM：推理时写入可更新参数

**Titans: Learning to Memorize at Test Time**，arXiv:2501.00663；**Fast-weight Product Key Memory**，arXiv:2601.00671，2026。

Titans将在线神经记忆作为内循环学习，局部键值关联目标更新memory参数，外循环训练其他参数。FwPKM把稀疏PKM变成按chunk局部更新的快权重记忆，也讨论稀疏寻址的slot利用与塌缩问题。

**可借鉴**：作为独立备选，先在小型多查询关联任务上比较快权重与我们的显式latent记录，测串扰、覆盖、遗忘、更新和恢复。

**边界**：改变运行时状态及优化语义，快权重和内循环状态也必须完整保存。不是原checkpoint换开关即可使用的等价优化。近期不优先改整个Qwen骨干。

## 两类容易混淆的研究

**MSA: Memory Sparse Attention for Efficient End-to-End Memory Model Scaling to 100M Tokens**，arXiv:2603.23516，已核对v2：有独立路由投影、路由预热、稀疏内容KV和分阶段训练，可借鉴训练先后次序。但其Memory Interleave步骤生成文档ID后会回取并追加原文，消融也显示原文重要；其最终QA成绩不能当作纯latent记忆已独立保存全部信息的证据。其大规模训练与100M-token部署不作为5080近期复现目标。

**Conditional Memory via Scalable Lookup: A New Axis of Sparsity for Large Language Models**，arXiv:2601.07372（Engram）：核心是静态N-gram嵌入查表与上下文门控，有助于静态模式存储。它不直接解决一次新经历写入、更新和未来回忆，不能因为名称带memory就视为我们最近的替代方案。

**FlashMem: Distilling Intrinsic Latent Memory via Computation Reuse**，arXiv:2601.05505、Findings ACL 2026论文亦已查阅：复用骨干KV生成latent memory值得关注，但我们的Qwen3.5混合GDN/attention结构和内存语义不同，不能直接迁移其共享KV实现或速度结论。

## 评测方向

**Zoology: Measuring and Improving Recall in Efficient Language Models**，arXiv:2312.04927：提出MQAR，提醒简单关联回忆任务可能不能反映多个查询下的真实检索。近期应采用同一记忆、多问题的受控套件，同时改变实体、属性、字段位置、时间和负候选；保留程序真值及固定独立开发/测试划分。

**LongMemEval**，arXiv:2410.10813：覆盖信息抽取、多会话推理、时间推理、知识更新、拒答。**MemoryAgentBench**，arXiv:2507.05257：覆盖准确检索、测试时学习、长程理解、选择性遗忘的增量多轮交互。**LongMemEval-V2**，arXiv:2605.12493：2026-05的新方向，关注环境静态状态、动态变化、工作流程、环境陷阱和前提识别，适合后续经历/任务接续。

这些基准用于扩充能力口径，不能把其评测内容用作本项目训练数据后再宣称零样本泛化，也不能放宽现有M5/native保持阈值。

## 5080上的近期实验顺序（尚未执行）

1. **先测底座与当前模块的上界**。固定同一记忆池，对同一实体的多个属性、多个实体和无证据问题分别提问。分别比较：底座看正确原文E+Q；底座看含干扰原文池+Q；当前学生仅看M+Q。由前两项区分底座自身选择能力，由第三项定位引入记忆后的额外损失。原文只作为标注清楚的对照，不混入M-only学生。
2. **消除可见捷径**。原文字段在前/中/后变化，实体与属性组合变化，正负记录新旧位置平衡；按当前生成器与seed重建最近240微批，78条双候选中64条正确记录比所补负记录更新，这只是训练数据偏置统计，不是模型采用该捷径的证据。从完整负池平衡采样，避免总补最早负记录。联合episode、语言、probe身份核对。候选数组置换仅作实现一致性检查：Reader没有候选序号编码，置换本身不是足够强的语义验收。
3. **固定数据比较监督方式**。当前CE/CF基线，对比CE/CF加证据条件KL；先用相同冻结0.8B底座产生教师目标，确认教师答案有效。顺序执行教师与学生以避免额外常驻大模型；教师分布缓存放E盘。显存、吞吐及缓存规模需实际测量，不能由论文硬件反推。源与新目标的预算、恢复身份和完整新run语义均须明确。
4. **确认选择瓶颈后，再改读取接口**。在固定Writer内容上验证局部记录相关性/门控；用同一M、不同Q检查所选内容是否变化。新门控、head损失或投影必须分别做对照，不同时堆叠。属于新增语义实验，仍需数值/恢复验证和有界正式小批。
5. **读写成立后再扩展**到2/4/8记录、多跳、更新、经历依赖。层次latent树、动态容量和快权重分别立项；保留普通语言保持与完整状态恢复。

最值得优先组合的是TransMem的证据条件监督、Cartridges的多样问题训练，以及M+/ElasticMem的查询条件选择思想。它们不是一个已验证的拼装模型；本项目需要通过以上对照逐项建立证据。
